# Security policy

HoloTable XR is a client-side Unity package with no network services, accounts or data collection.
Still, if you find a vulnerability (for example in how external tracking data is handled), please
**do not open a public issue**. Use GitHub's *Report a vulnerability* (Security tab → Advisories)
on this repository. You will get an answer as soon as possible, and credit if you wish.

Supported versions: the latest release on `main`.
