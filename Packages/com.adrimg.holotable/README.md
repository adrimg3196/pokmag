# HoloTable XR (Unity package)

Mixed-reality tabletop framework: physical Pokémon TCG cards, Magic: The Gathering cards and Warhammer 40K
miniatures become animated 3D holograms.

- Install: *Package Manager ▸ + ▸ Add package from git URL* →
  `https://github.com/adrimg3196/pokmag.git?path=/Packages/com.adrimg.holotable`
- Quick start: **HoloTable ▸ Create Demo Scene**, then Play (desktop simulator, no AR needed).
- Docs, tracking setup and contribution guide: https://github.com/adrimg3196/pokmag

Unofficial fan project. Game names are trademarks of their respective owners; no official assets are included.
